# mindie-agent-wb 0.1.19: Great Subtraction and WorkBuddy UX Upgrade

[中文](mindie-agent-wb-0.1.19.md)

- **Great Subtraction: 16 duplicate runtime modules removed; only 6 thin scripts remain**: `plugins/mindie-agent/scripts/` now contains `mindie_launch.py`, `bridge.py`, `mcp_server.py`, `wb_transcript.py`, `wb_install.py`, and `setup.py` (about 1,060 lines; hard ceiling 1,200). `host_adapter.py`, `wb_native_compat.py`, `knowledge_cli.py`, `admission.py`, `identity.py`, `paths.py`, `storage_lifecycle.py`, and the other legacy modules are deleted; the runtime delegates directly to `mindie-harness v0.1.3`.
- **Converged 15-tool `wb` remote profile**: `remote-dev v0.11.14` natively serves `remote_Read`, `remote_Write`, `remote_Edit`, `remote_MultiEdit`, `remote_Bash`, `remote_Glob`, `remote_Grep`, `remote_TaskOutput`, `remote_NotebookEdit`, `remote_TaskStop`, `remote_ViewImage`, plus `remote_auth`, `remote_probe`, `remote_artifact_pull`, and `remote_artifact_push`. `remote_BashOutput` and `remote_KillShell` are no longer exposed.
- **Strictly disjoint MCP surfaces**: `mindie-remote-dev` (15 `wb` tools), `mindie-tools` (11 deterministic components plus `mindie_doctor`, zero `knowledge_*` duplicates), and `mindie-knowledge` (5 `knowledge_*` tools). All three support standard zero-`_meta`, zero-`PreToolUse`-binding `tools/call`.
- **`mindie_doctor` readiness check**: one read-only check for the profile, active runtime, component bindings, and optional remote reachability. Run it once after install; a failed check is reported once and never blocks the task.
- **Silent hooks and `<100ms` fast paths**: `UserPromptSubmit`, `PreToolUse`, `SessionStart`, and unconfigured `Stop` complete in pure stdlib and return `{"suppressOutput": true}` with zero SQLite creation. `PreToolUse` explicitly denies forged `_session_id` / `mindie_activation` keys and never auto-approves host permission prompts.
- **Consent-first `Stop` with revocation preservation**: only when `mindie-consent.json` selects `contribute` / `local-only`, `mindie-community.json` is enabled, and the workspace is inside absolute `project_roots` does `Stop` activate the default lease (`not_before=0.0`) and call `capture_hook(..., timeout=6.0)`. Explicit `inactive` revocation is preserved forever.
- **Receipt Honesty**: when the harness reports `knowledge_unavailable`, knowledge calls fall back to `mindie_knowledge.loop.transport`; `distill_selected` is preserved and a local `Admission.finish` `OSError` / `sqlite3.Error` keeps `isError=False` with `receipt_warning` plus `receipt_unconfirmed=True`.
- **Install and first-run UX**: adds the one-line `uv run https://github.com/mindie-agent/mindie-agent/releases/latest/download/install.py --host wb` installer. `gh` is optional and never a blocker. A three-question, `gh`-aware `AskUserQuestion` onboarding covers the workspace, a dynamic `contribute` vs `local-only` sharing recommendation, and a one-step `remote_auth(..., save_default=True, discover=True)` SSH NPU connection (terminal mode may append `--password` for hidden input). Finish with `mindie_doctor` and one polite Star line.
- **Installer and cold bootstrap**: adds `plugins/mindie-agent/runtime-requirements.txt` (10 lines matching the `pyproject.toml` component Git pins) so cached `~/.workbuddy/plugins/cache/...` copies can cold-bootstrap. `wb_install.py` now owns LF cleaning, verified-Python pinning, Connector marketplace registration, and stale-version pruning.
- **Non-Blocking Task Continuity Rule**: `remote-dev`, `coordinator`, `knowledge`, and `mindie_doctor` are accelerators, NEVER roadblocks. Report a tool failure once (reconciling uncertain writes first), then continue immediately through native `ssh`/`scp`, local scripts, or other authorized host tools.

# mindie-agent-wb 0.1.7

[English](mindie-agent-wb-0.1.7.en.md)

同步根 marketplace、原生插件和 Connector 的版本；安装合同测试读取真实插件版本，PR CI 在 Linux / Windows 执行全部本地合同。需要实际网络的 Tier 3 验收通过 `--live-host` 显式运行，测试使用指定解释器和隔离配置，不自动借用用户的其他宿主安装。

`0.1.6` 在发布候选测试阶段失败，没有正式 Release；保留该标签和失败记录，本补丁使用新的不可变标签。

## 任务连续性与 SSH 首次连接修复

- 用户已给出凭据时，优先复用共享 `remote_auth` 完成密码认证、公钥安装和密钥验证，不以缺少预建认证配置阻断任务。
- 可选知识、诊断、组件安装和本地记账失败仅影响对应能力；继续可独立推进且已获授权的原生工作，保留任务身份、资源约束和活动作业。
- 远端主操作成功而本地回执失败时保留成功结果和明确警告；外部写入结果未知时先对账再重试。
- 不新增用户业务服务器、NPU 推理或模型精度实测声明。验证范围为本地合同、跨平台 CI、真实隔离 SSH 服务和发布基准。
